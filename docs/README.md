# Documentación del proyecto

Esta carpeta reúne los documentos que explican las decisiones no ejecutables de la web, para mantener la raíz del repositorio reservada a configuración y código de aplicación.

| Archivo | Propósito |
| --- | --- |
| `design-direction.md` | Dirección visual, principios de marca y decisiones editoriales del portafolio. |
| `maintenance-todo.md` | Lista de control para las tareas de mantenimiento y organización. |

El código funcional vive en `client/`, mientras que los elementos de compatibilidad del proyecto se mantienen en `server/` y `shared/`.
